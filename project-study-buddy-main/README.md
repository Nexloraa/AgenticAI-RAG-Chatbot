# 📚 StudyBuddy – Agentic RAG NCERT Chatbot

StudyBuddy is an AI-powered RAG chatbot built using CrewAI, Groq LLMs, ChromaDB, and Streamlit.
It allows students to ask questions directly from NCERT PDF textbooks and get accurate answers with citations.

## 🚀 Features
- Agentic RAG Pipeline
- Groq Llama3.3 70B Model
- PDF-based contextual answers
- Backend: FastAPI
- Frontend: Streamlit
- Vector DB: ChromaDB
- Real-time querying

## 🛠 Tech Stack
| Component | Technology |
|-----------|------------|
| Frontend | Streamlit |
| Backend | FastAPI |
| Embeddings | Sentence Transformers |
| LLM | Groq Llama3.3 70B |
| Vector DB | ChromaDB |
| Agents | CrewAI |
